Family Location Server
=====================

1. Double-click FamilyLocationServer.exe
   Leave the window open. It should say: Server listening on port 8000
   Windows may say it protected your PC because this file is unsigned.
   Choose More info, then Run anyway.
   If a firewall prompt appears, allow it on Private networks.

2. If nothing can connect, right-click allow-firewall.ps1 and run it
   with PowerShell as Administrator.

3. On the phone app, set the server URL to one of:
   - Same Wi-Fi:  http://<this PC's LAN address>:8000
   - Tailscale:   http://<this PC's 100.x.x.x address>:8000

4. Endpoints
   GET  /health
   POST /send    JSON {"userId","groupId","lat","lon"}
   GET  /fetch?userId=Alice&groupId=Fam1

The source folder is the same program, if you want to rebuild it.
cpp-httplib and nlohmann/json in source/include are third-party MIT headers.

This is a test server. No password, no HTTPS. Keep it on your tailnet only.
Do not forward port 8000 to the public internet.
