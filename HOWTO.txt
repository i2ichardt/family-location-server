Family location server
======================

1. Double-click FamilyLocationServer.exe.
   The window lists people and shared places.
   It listens on port 8000 for your home network and for Tailscale.
   Windows may say it protected your PC because this file is unsigned.
   Choose More info, then Run anyway.
   If a firewall prompt appears, allow it on Private networks.

2. Minimizing the window keeps the server running. It stays on the taskbar.
   Closing the window stops the program and ends the process.
   There is no system-tray icon.

3. If nothing can connect, right-click allow-firewall.ps1 and run it
   with PowerShell as Administrator.

4. On each phone, open Family, then Settings.
   Home Wi-Fi address:  http://<this PC's LAN address>:8000
   Tailscale address:   http://<this PC's 100.x address>:8000
   Leave the choice on Auto. Auto tries home first, then Tailscale.
   Set the same group name on every phone, then Save.

The window shows two addresses, both with port 8000:

- Home is this PC's LAN address. Phones on the same Wi-Fi use it.
- Tailscale is filled in when Tailscale is connected. You can edit the saved Tailscale address and click Save address. Phones that are away use that one.

The map on the left shows everyone who has sent a pin. Satellite switches the picture to aerial photos. Drag to move the map. The wheel zooms.

Delete person, Delete group, and Delete place remove test data. Deleting a group removes its people, photos, and places.

Closing the window stops the program. Minimizing it leaves it on the taskbar.

There is no password and no HTTPS. Do not forward port 8000 to the internet.
