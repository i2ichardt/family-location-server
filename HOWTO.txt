Family location server
======================

1. Double-click FamilyLocationServer.exe.
   The window lists people and shared places.
   It listens on port 8000 for your home network and for Tailscale.
   Windows may say it protected your PC because this file is unsigned.
   Choose More info, then Run anyway.
   If a firewall prompt appears, allow it on Private networks.

2. Minimizing the window keeps the server running. It stays on the taskbar.
   Closing the window stops the program and ends the process.
   There is no system-tray icon.

3. If nothing can connect, right-click allow-firewall.ps1 and run it
   with PowerShell as Administrator.

4. On each phone, open Family, then Settings.
   Home Wi-Fi address:  http://<this PC's LAN address>:8000
   Tailscale address:   http://<this PC's 100.x address>:8000
   Leave the choice on Auto. Auto tries home first, then Tailscale.
   Set the same group name on every phone, then Save.

The window shows two addresses, both with port 8000:

- Home is this PC's LAN address. Phones on the same Wi-Fi use it.
- Tailscale is filled in when Tailscale is connected.
- The saved Tailscale address is under File, then Settings. That is the address phones use when they are away. Include http:// and :8000.

The map shows everyone who has sent a pin. View, then Satellite switches to aerial photos. View, then Pause updates freezes the map and the list. Drag empty map to pan. The wheel zooms, unless a place is selected.

People and places are listed by group. Each person has History, Edit, and Delete. History shows only that person's check-ins. File, then Check-in database, is the full trail as coordinates. Deleting a group removes its people, photos, and places.

Each saved place has its own arrive and leave distance, in meters. Drag a place's dot on the map to move it. Click a place to select it, then scroll the mouse wheel to change its distance. The circle on the map is that distance. Someone is arrived while they are inside it, and left once they move past it. A park can be wider than a house.

Click empty map to clear the selection so the wheel zooms again.

Profile photos update when a phone saves a new one. Battery percentage is shown on each person when the phone sends it.

File, then Open saved data opens the folder next to the program. File, then Exit stops the program, the same as closing the window.

There is no password and no HTTPS. Do not forward port 8000 to the internet.
